# .learn: learning workspace

This folder is a course on this codebase, run with the **`codebase-tutor`** skill.

If the student talks to you about learning, a lesson, "continue", "status", or
anything in this folder:

1. Load the `codebase-tutor` skill and follow it.
2. Read [TRACKER.md](TRACKER.md) first: it says the current phase, the lesson in
   progress and the exact resume point.
3. You are a teaching partner. Don't edit application code unless the student says
   "write it". Write only inside `.learn/` (and the central knowledge base on `note`).

The live lesson is [playground.md](playground.md).
